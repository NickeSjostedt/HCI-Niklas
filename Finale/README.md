# HiFi Kompass

En fristående statisk kopia av samtalssidan och Mindmap mode från ValkompanjonenMoa, med partiväljaren och partichatten från ValstuganPrototype.

Startsidan visar samtalet. Välj Politisk karta i sidomenyn för att jämföra **Din karta** med ett parti sida vid sida. Välj parti ovanför den högra kartan för att byta jämförelse. Kartorna använder samma politikområden; partiernas ståndpunkter är inte verifierade eller inlagda i prototypen.

Rangordningen av huvudkategorier och underkategorier sparas separat för din egen karta och varje parti. Använd knapparna ovanför respektive karta för att öppna rangordningen.

Alla noder ryms automatiskt i respektive karta. Dra bakgrunden för att panorera, dra en nod för att flytta den, dubbelklicka på en nod för att centrera och zooma in, eller använd mushjulet och zoomknapparna. Välj **Visa alla noder** för att återställa helhetsvyn. Varje karta har oberoende vy- och zoomkontroller.

## Öppna appen

Öppna `index.html` direkt i webbläsaren; ingen lokal server eller byggprocess krävs. Google Fonts laddas från nätet; systemets sans-serif- och serif-fallbacks används annars.
